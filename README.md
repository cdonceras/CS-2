# Pisay Personality Profile

## Overview

Pisay Personality Profile is a simple C++ personality test inspired by the Myers-Briggs Type Indicator (MBTI). The program asks the user a series of questions and determines their personality type based on their selected answers. It is designed to help students better understand their personality preferences and discover people with similar characteristics.

## Features

* Interactive personality test
* Multiple-choice questions
* Determines the user's four personality dimensions
* Calculates the user's personality type
* Displays the resulting four-letter personality type
* Provides a simple description of the user's personality
* Uses conditional statements, loops, functions, and other basic C++ programming concepts
* Menu-driven program for easier navigation

## How to Run

### Requirements

* A computer with a Python compiler
* Any Python IDE or compiler 

### Steps

1. Open the project's Python source file.
2. Compile the program using a Python compiler.
3. Run the compiled program.
4. Select the appropriate option from the menu.
5. Answer each personality-test question.
6. The program will calculate and display the resulting personality type.
