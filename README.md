# MindType: An Interactive Personality Exploration and Self-Reflection Program

## Overview / Description

MindType is an interactive personality exploration program designed primarily for teenagers ages 13–19. It uses a series of age-appropriate questions about preferences, behaviors, and everyday situations.

The program analyzes the user's answers across four personality dimensions:

* Extraversion (E) / Introversion (I)
* Sensing (S) / Intuition (N)
* Thinking (T) / Feeling (F)
* Judging (J) / Perceiving (P)

The results are combined to generate a four-letter personality type, along with a brief explanation of the user's identified preferences. The result is intended as a starting point for self-reflection and should not be treated as a fixed definition, diagnosis, or complete representation of a person.

## Features

* **Introduction and Instructions**
  Explains the purpose of MindType and how to answer the questions.

* **Interactive Personality Questionnaire**
  Presents multiple-choice questions based on everyday situations and preferences.

* **Input Validation**
  Checks whether the user's answer is a valid A or B response and asks the user to try again if the input is invalid.

* **Response and Score Storage**
  Temporarily stores the user's responses and scores for processing.

* **Personality Score Calculation**
  Compares the scores for each personality dimension.

* **Personality Type Generation**
  Combines the four determined preferences into a four-letter personality type, such as `ENFP`.

* **Personality Results**
  Displays the personality type, personality preferences, a brief description, possible strengths or tendencies, and reflection prompts.

* **Restart or Retake Function**
  Allows users to take the questionnaire again and see how different answers can affect their results.

## How to Run / Requirements

### Requirements

The project proposal specifies a text-based interactive program and plans to apply concepts such as:

* Variables and data structures
* Modular programming using functions
* Selection structures
* Input validation
* String processing
* Appropriate programming libraries and methods
* Debugging and testing
* Code documentation

The project will also use GitHub for version control.

### How to Run

1. Open the MindType project in the programming environment used by the development team.
2. Run the main program.
3. Read the instructions shown on the screen.
4. Answer each question using **A** or **B**.
5. Wait for the program to calculate the results.
6. View your generated four-letter personality type and its interpretation.
7. Choose whether to retake the test or exit the program.

## Sample Interaction / Example Output

```text
Welcome to MindType!

Answer each question by entering A or B.

Question 1:
When you are in a social situation, you prefer to:

A. Talk and interact with other people
B. Spend time by yourself or with a small group

Your answer: A

Question 2:
When solving a problem, you usually:

A. Focus on facts and details
B. Think about possibilities and ideas

Your answer: B

...

Thanks for taking the test!
Calculating results...

You are an ENFP.

[Personality description]

Retake test? (Yes/No): No

Thank you for using MindType!
```

The program validates answers and displays an error message when an invalid response is entered:

```text
Invalid input. Please enter A or B.
```

The proposed program follows the flow of collecting answers, validating input, storing responses, calculating scores, determining the four personality preferences, generating the personality type, and displaying the results.
